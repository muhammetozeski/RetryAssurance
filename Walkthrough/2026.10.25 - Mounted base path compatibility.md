# Mounted base path compatibility

Retry Assurance can now be built for `/retry-assurance/` while the independent origin retains its existing root paths and database. The frontend uses its application base for navigation, API calls, invitations, downloads and runner commands. The runner validates the complete base before accepting a scenario grant.

The shared backend handler preserves the actual request URL and origin. Existing credential hashes remain valid. A different endpoint salt cannot silently replace the run key for an earlier mint request identity; that replay returns a named conflict. The existing independent webhook is retained and mounted billing remains unavailable without explicit provider settings.

Local acceptance completed: 74 actual-SQL service assertions, 14 C# runner assertions, authored-script parsing and a mounted Release publish. The built compressed bootstrap matches the plain file, SPA rewrites exclude static assets, and the generated ZIP contains current clients and prefixed instructions. The integrating host still owns its actual mounted HTTPS publication and browser acceptance. See [the mount contract](../docs/Subpath-Mount.md) for the exact file/environment manifest and build command.
